# PikaOikeus 7.0 — turvallinen kehityspohja

Tämä haara ei ole viranomaiskäyttöön soveltuva eikä sisällä oikeudellisesti validoitua päätösmoottoria.

## Ensimmäisen vaiheen korjaukset
- Euromäärissä tuetaan tuhaterottimia ja desimaalipilkkua.
- Puuttuvaa tai tuntematonta euromäärää ei muuteta nollaksi.
- Luonnollisen kielen kyllä/ei-vastauksia tulkitaan hieman joustavammin.
- Lisätään regressiotestit.

## Seuraavat vaiheet
1. Erota käyttöliittymä ja sääntölogiikka omiin moduuleihin.
2. Lisää rakenteiset vastausvaihtoehdot oikeudellisesti ratkaiseviin kysymyksiin; pelkkä regex ei ole luotettava.
3. Tarkistuta oikeudelliset säännöt ja lainkohtien ajantasaisuus asiantuntijalla.
4. Tee tietosuojan vaikutustenarviointi ennen oikeiden tapaustietojen käyttöä.
5. Lisää tekoäly vasta palvelinpuoleisen tietoturva-arkkitehtuurin, käyttäjän vahvistuksen ja ihmisen valvonnan jälkeen.

Testit: `npm test` (Node.js 20+).
